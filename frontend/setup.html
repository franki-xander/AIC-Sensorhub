Connect Your Data Source

Follow these steps to link your Google Sheet. This takes about 5 minutes. You can re-run this wizard at any time to switch to a different sheet.

1
Create (or open) your Google Sheet

Open Google Sheets and create a new spreadsheet. Name it anything you like — for example, My Sensor Data.

If you already have a sheet from a previous setup, you can use that instead — just make sure the Apps Script is still deployed (check Step 2).

Open Google Sheets →
2
Install the Sensorhub Apps Script

In your Google Sheet, open Extensions → Apps Script. Delete any existing code in the editor, then paste the code below:

//Loading script code...

After pasting, click Deploy → New Deployment. Configure it as:

  • Type: Web App
  • Execute as: Me
  • Who has access: Anyone

Click Deploy, authorize when prompted, then copy the Web App URL that appears.

3
Paste your Web App URL

The URL ends in /exec

Open your Drive folder → copy the ID from the URL: drive.google.com/drive/folders/THIS_PART

4
Flash your ESP32

Download the firmware template below. Open it in Arduino IDE, fill in your WiFi credentials and the values shown, then flash to your device.

GOOGLE_SCRIPT_ID = — paste your Script URL first —
SENSOR_ID = "my_sensor_1" // change to something unique

Waiting for your first reading
