AIC Sensorhub is a web-based IoT monitoring platform developed by Aldwyn James N. Bernardo in cooperation with the Ateneo Innovation Center. It was originally created to support the research project of Ramos, Andal et al., and is made available for further use by the developer and AIC.

The platform enables users to connect ESP32 microcontrollers to a personal dashboard through their own Google Sheets, providing live sensor monitoring, remote configuration, and data archiving without storing sensor data on any third-party server outside of the user's own Google account.

03
General Instructions

Follow these steps after registering to connect your hardware to the dashboard.

1
Create a blank Google Spreadsheet. Then open Extensions → Apps Script inside the spreadsheet.
2
Copy the provided script code from the setup page and paste it into the Apps Script editor. Deploy it as a Web App — set Execute as: Me and Who has access: Anyone.
3
Copy the resulting Web App URL and paste it into Step 3 of the setup page. Optionally, provide a Google Drive folder ID where CSV archives will be saved.
4
Download the template firmware from the setup page and flash it to your ESP32 using Arduino IDE. Fill in your WiFi credentials, Google Script ID, and a unique Sensor ID. A ready-to-use DHT22 example is also available if you are working with temperature and humidity sensors.
5
Wait for the first reading to appear. Once confirmed, you will be directed to the dashboard.
6
On the dashboard, add Sensor Pages for each device you want to monitor. Each page can display specific data fields from any connected sensor. Pages can be added, edited, or removed at any time.
7
Use the Archives page to export sensor data as CSV files. Archives are saved directly to your linked Google Drive folder on request. You may export incrementally, from a specific date, or export all data at once. Individual sensors can be excluded from any archive run.
